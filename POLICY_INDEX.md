# Chính sách hỗ trợ / Support Policy

## <a id="vietnamese">Tiếng Việt</a>

### 1. Kênh hỗ trợ

Hỗ trợ cho Orbis Agent được cung cấp thông qua:

- GitHub Issues
- Repository discussions hoặc channels hỗ trợ được chỉ định
- Email: nimborasupport@gmail.com

### 2. Thời gian phản hồi

Chúng tôi cố gắng phản hồi trong thời gian hợp lý, tùy thuộc vào mức độ nghiêm trọng và loại yêu cầu.

### 3. Yêu cầu hỗ trợ

Người dùng nên cung cấp:

- Mô tả vấn đề
- Môi trường sử dụng
- Bước tái hiện
- Log hoặc ảnh chụp nếu cần

### 4. Không hỗ trợ

Chúng tôi không cam kết hỗ trợ các trường hợp:

- Sử dụng sai mục đích theo các điều khoản
- Mục đích bất hợp pháp hoặc xâm phạm quyền khác
- Hành vi lạm dụng hoặc quấy rối đối với cộng đồng

## <a id="english">English</a>

### 1. Support Channels

Support for Orbis Agent is provided through:

- GitHub Issues
- Repository discussions or designated support channels
- Email: nimborasupport@gmail.com

### 2. Response Time

We aim to respond within a reasonable timeframe depending on severity and request type.

### 3. Support Requests

Users should provide:

- Problem description
- Environment details
- Reproduction steps
- Logs or screenshots if needed

### 4. Unsupported Cases

We do not guarantee support for:

- Misuse outside the documented scope
- Illegal or unauthorized use
- Abusive or harassing behavior toward the community
