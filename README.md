# Orbis Agent

A powerful AI agent tool for enhanced productivity and workflow automation.

## 📋 Overview

Orbis Agent is designed as a modern, privacy-first AI assistant to support your daily workflows and tasks.

## 🚀 Quick Start

### Prerequisites
- Node.js 16+
- Rust 1.70+ (for Tauri backend)

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```
